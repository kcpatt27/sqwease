## Summary

Each show/rate performs multiple synchronous writes of the entire SRS object.

## Evidence

saveSRS writes 3 keys and is called when showing each new card and on each rating.

## Proposed fix

Write on rating only (not on every card show) and/or persist one namespaced object; debounce where safe.

## Acceptance criteria

A study session performs at most one write per user action.
