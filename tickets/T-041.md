## Summary

Dynamically created token inputs rely on visual column headers only.

## Evidence

createTdWithInput creates inputs with no aria-label; headers are not associated.

## Proposed fix

Add aria-label derived from column + token index (and real `<label>`/caption where possible).

## Acceptance criteria

Each token input has an accessible name identifying field and row.
