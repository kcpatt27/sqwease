## Summary

kanji loads `assets/store.js`/`i18n.js`/`langs.js` but still uses bare `localStorage`; editor loads `store.js`/`langs.js` and uses neither; kana loads the same set only for the nav/title.

## Evidence

`localStorage.getItem(...)`/`setItem(...)` in kanji.html despite the safe store being loaded.

## Proposed fix

Either drop the unused `<script>` tags or route storage through `SqweaseStore`.

## Acceptance criteria

No page includes an asset it does not use; storage access goes through the safe helper.
