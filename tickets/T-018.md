## Summary

When segmenter output count differs from romaji word count, buildTokensFromSegmenter returns null and the item silently downgrades to less-accurate word coloring.

## Evidence

Plan: "When segments.length !== romajiWords.length, the function returns null. Those items then use word-based coloring ... which can misalign." Cup 2 sentences hit this path.

## Proposed fix

Log/flag mismatches in development and prefer the token path; keep the fallback but make it observable rather than silent.

## Acceptance criteria

Mismatches are reported in a debug channel; no production path silently changes coloring strategy unobserved.
