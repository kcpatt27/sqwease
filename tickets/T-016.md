## Summary

`isParticleToken` returns true purely on romaji, so kanji nouns whose reading equals a particle are never colored.

## Evidence

`isParticleToken({ja:'蚊',romaji:'ka'})` is true; likewise 野(no), 屋(ya), 戸(to), 藻(mo), 駄(da). shouldColorToken then excludes them.

## Proposed fix

Prefer an explicit `token.isParticle`/POS field; fall back to romaji matching only when the token is kana-only (the documented rule).

## Acceptance criteria

Kanji homophone fixtures (蚊/野/屋/戸/藻/駄) are colored; true kana particles stay uncolored.
