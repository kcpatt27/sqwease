## Summary

Leftover `#region agent log` instrumentation POSTs page content to `http://127.0.0.1:7244/ingest/<uuid>` on every generated item, every rendered list row, and every practice card.

## Evidence

boxes.html:766 `fetch('http://127.0.0.1:7244/ingest/7365a28b-...',{method:'POST',...body:JSON.stringify({...data:{ja:item.ja,tokens:tokens}})})`; fires hundreds of times per load, fails/errs offline, and leaks JA/romaji/EN content off-page.

## Proposed fix

Delete every `// #region agent log ... // #endregion` block and every hardcoded 127.0.0.1 fetch in boxes.html and kana-charts.html. If diagnostics are needed later, gate behind an explicit debug flag, never a hardcoded endpoint.

## Acceptance criteria

No occurrence of `127.0.0.1:7244` or `region agent log` remains in the repo; boxes/kana pages load with zero network requests other than their own assets.
