## Summary

Make the static app installable and usable offline: web app manifest, a service worker caching the shell/data, and IndexedDB for the (growing) review log and settings.

## Evidence

PWA = manifest + service worker + HTTPS; service workers require HTTPS/localhost, so the file:// path must remain supported separately. See docs/research/2026-10-09-srs-fsrs-and-upgrade-research.md §5.

## Proposed fix

Add manifest.webmanifest + icons; register a service worker on HTTPS only (feature-detect and skip on file://); move review-log persistence toward IndexedDB (with a localStorage fallback); add an offline indicator.

## Acceptance criteria

App installs and loads offline over HTTPS; file:// still works without a service worker; no console errors.
