## Summary

Frequency lists are surface forms, so decks contain inflected verbs/plurals and a few unaccented duplicate variants, which inflates the count and can split SRS progress on the same lemma.

## Evidence

Spanish: tengo/tiene/tienes all present; French: etre/être, coeur/cœur duplicates; Korean: inflected eojeol.

## Proposed fix

Add an optional lemma column and a dedupe-by-lemma pass; merge accent variants to the standard form.

## Acceptance criteria

Decks carry a lemma (or a documented decision not to); duplicate variants are merged.
