## Summary

Theme bootstrap, CSS tokens, toggle CSS/JS, nav markup, and SRS/phase wiring are copy-pasted across all six pages.

## Evidence

Identical :root/dark token blocks, .theme-toggle CSS, toggleTheme(), and saveSRS/loadSRS/getOrInitCard/getRomajiPhase duplicated per page.

## Proposed fix

Create minimal shared assets (theme.css, theme.js, a safe-storage/SRS helper, util) and consume them from every page. Keep page-specific CSS inline.

## Acceptance criteria

Theme toggle and SRS storage have one implementation; changing a token updates all pages.
