## Summary

Remove buttons capture a render-time array index; if the list changes before the click, the wrong entry is deleted.

## Evidence

Kanji remove buttons embed `data-index` from the render-time position; the handler then runs `arr.splice(idx, 1)`; adding an entry via lookup after render shifts indices.

## Proposed fix

Key rows by a stable id (character string) and filter by id instead of slicing by position.

## Acceptance criteria

Add a personal kanji, remove an earlier row, and confirm the intended row is removed.
