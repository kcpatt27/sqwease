## Summary

A transient network failure writes a partial dataset with no failure signal; the cap comment (240) contradicts MAX_KANJI (250); fetch has no timeout.

## Evidence

Per-char catch warns then continues; unconditional writeFileSync.

## Proposed fix

Add timeout + limited retries, align the comment/cap, and fail (or write to temp then rename) if any entry was skipped.

## Acceptance criteria

A failed fetch aborts the build without overwriting good data.
