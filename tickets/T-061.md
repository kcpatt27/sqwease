## Summary

Card ids are derived from text (`box-<ja>-<en>`) or array index (`fc-<i>`), so editing content or reordering the deck orphans/reassigns progress.

## Evidence

`getItemId(item) { return 'box-' + item.ja + '-' + item.en; }` and `'fc-' + i`.

## Proposed fix

Introduce stable content ids (vocab id column; set+box+word key) and migrate stored SRS keys.

## Acceptance criteria

Reordering the deck or editing a sentence preserves existing SRS progress.
