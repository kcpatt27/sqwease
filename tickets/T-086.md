## Summary

The Flashcards card hint/description are target-agnostic and hardcode "1,500 high-frequency words" and "romaji", which are wrong for the 30-word Latin/Chinese decks.

## Evidence

<span class="hint" data-i18n="index.hint.flashcards">1,500 high-frequency words</span> renders identically for every target.

## Proposed fix

Make the hint target-aware (use the deck count) or generic ("High-frequency words"), and drop "romaji" from the description for non-Japanese targets.

## Acceptance criteria

The menu reflects the active target (e.g. "30 words" / no romaji claim for Spanish).
