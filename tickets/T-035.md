## Summary

Several text colors fall below AA contrast on their backgrounds.

## Evidence

`.instruction { color:#ccc }` on white is about 1.6:1; `.loading { color:#747d8c }`.

## Proposed fix

Use the shared secondary-text token (T-054) and verify each against its background.

## Acceptance criteria

All body/secondary text passes 4.5:1; token used consistently.
