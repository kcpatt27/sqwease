## Summary

Generic tokenizer adapter special-cases literal content (`ごはん`, `お好み`, `焼き`, `時`, `ます`, `か`) with hand-written merge/split functions.

## Evidence

Functions mergeOkonomiyaki, mergeGohan, splitGohanCompound, mergeDigitTime, mergeMasu, splitTrailingKa hardcode strings; each new slot phrase risks a new case.

## Proposed fix

Drive normalization from a data table in content/ (or tokenize generated sentences offline once) instead of code special cases.

## Acceptance criteria

Adding a new slot phrase requires no code change; existing 5 tabs still color correctly.
