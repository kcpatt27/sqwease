## Summary

Token `romaji` is set to the pronunciation column `p` (e.g. `mizu (mee-zoo)`) instead of `Romaji.kanaToRomaji(kana)`, producing bogus colored words and empty colored spans.

## Evidence

`item.tokens = [{ ja: w, kana: w, romaji: p, ... }]`; 95 generated tokens contain parentheses, 248/1500 items carry parentheticals. `colorizeByWords` then splits the parenthetical into a fake colored word and emits an empty JA span.

## Proposed fix

In the build script require romaji.js and set `romaji: Romaji.kanaToRomaji(kana)`, keeping `p` only for the pronunciation line (or add a dedicated reading column).

## Acceptance criteria

No generated token romaji contains spaces or parentheses beyond intended word breaks; no empty colored spans render for flashcard words with a parenthetical pronunciation.
