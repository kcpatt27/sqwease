## Summary

Add a "hear the word/sentence" control using SpeechSynthesis (target-language voice), degrading gracefully when a language voice is unavailable or synthesis fails.

## Evidence

MDN Web Speech API provides SpeechSynthesis/SpeechRecognition browser-native with no server; audio is table-stakes in language apps (Jolito, Jiaci pre-cache neural audio; that needs a backend and is out of scope for v1).

## Proposed fix

Add a speaker button on the card; pick a voice matching the target lang; handle "language-unavailable"/"language-not-supported" with a visible fallback; add an aria-live status. Do not block the flow when audio is unavailable.

## Acceptance criteria

Word and sentence can be played where a voice exists; a clear, non-blocking message appears where it does not; the control is keyboard accessible and labelled.
