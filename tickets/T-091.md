## Summary

boxes/kana/kanji/editor still re-declare `.theme-toggle` and a `body { font-family: "Segoe UI" }` even though `assets/theme.css` now owns both; only index/flashcards were cleaned.

## Evidence

Duplicated `.theme-toggle`/`.icon-dark`/`.icon-light` blocks remain on the four pages.

## Proposed fix

Delete the duplicated blocks and use `var(--ui-font)`.

## Acceptance criteria

Only `assets/theme.css` defines the toggle and base font; no page duplicates them.
