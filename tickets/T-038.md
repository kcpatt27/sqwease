## Summary

Tables lack captions and header scope; one header cell is empty.

## Evidence

renderTable emits `<th>` without scope; kanji table has an empty `<th>`; token table headers are terse.

## Proposed fix

Add `<caption>` and `scope="col"/"row"`; label the empty header.

## Acceptance criteria

Screen readers can navigate tables by header association.
