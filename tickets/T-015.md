## Summary

Several kana paths convert incorrectly: orphan long-vowel mark, small-katakana loanword combos, vu, combining dakuten, sokuon before a vowel, and ん before full-size ヤ.

## Evidence

`ー`->' ' (space), `ヴ/ゔ`->'', `ティ`->'tee', `ファ`->'fu', `ウィ`->'u', combining `か\u3099`->'ka', `っあ`->'a', `あっ`->'at'; the ん lookahead omits full-size katakana ヤ.

## Proposed fix

Map vu and small-katakana combos, return empty/ō for orphan ー, NFC-normalize input, handle sokuon before vowels, and extend the ん lookahead. Add each case to the shared test list (T-023).

## Acceptance criteria

All listed inputs convert to the documented Hepburn output; regression tests cover each case.
