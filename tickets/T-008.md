## Summary

A planned fix was never applied: generated tokens always set `en: null`, so slot-filled items fall back to the word-based SOV reversal that mis-colors EN.

## Evidence

boxes.html:644 still `en: null` for every generated token; only pre-tokenized fixed items get item.en. Plan documents objects/verbs (coffee/like, Japan/go) being color-swapped as a result.

## Proposed fix

Implement the documented plan: split the EN sentence into words and assign `token.en` to the aligned JA content token, then color from tokens.

## Acceptance criteria

Reasons/Wants/Studying/Routine sentences no longer show the object color on the verb or vice versa; verified on all 5 tabs.
