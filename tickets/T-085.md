## Summary

The per-day new-card counter uses one key for every language, while SRS cards are namespaced per language. Studying one language consumes the others' new-card budget, so a second language can show "No cards due" with all cards still New.

## Evidence

SRS_NEW_KEY = 'sqwease-flashcards-new-today' (single); item ids are 'es-0001'/'ja-1' (per language); buildDueQueue caps fresh cards by `newCardsIntroduced < newCardsPerDay`.

## Proposed fix

Namespace the daily counter per target (`sqwease-flashcards-new-today:<code>`) and reset the in-memory count on `sqwease:targetchange`.

## Acceptance criteria

Studying 20 Spanish words does not consume the Japanese new-card budget; each language has its own daily count.
