## Summary

Error messages instruct end users to run build scripts.

## Evidence

"Run: node scripts/build-boxes-data.js then open boxes.html..."

## Proposed fix

Show a user-friendly message and put the developer detail in the console.

## Acceptance criteria

User-facing errors contain no shell instructions.
