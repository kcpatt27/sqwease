## Summary

Lookup depends entirely on a third-party network API, so it degrades offline, on CORS/rate-limit failures, and leaks queried characters.

## Evidence

`https://kanjiapi.dev/...` fetched per lookup; error text on failure. The repo already ships 240 kanji in content/common-kanji.json.

## Proposed fix

Load the bundled dictionary first and call the API only for characters not found locally, with an explicit "not in local dictionary" state.

## Acceptance criteria

Lookup works offline for bundled kanji; a network failure only affects non-bundled characters and shows a clear message.
