## What's wrong

`scripts/check.js` only verifies the three Japanese generated files exist; it never validates the per-language decks, so a malformed deck (wrong header, duplicate words, broken rank order, stray tabs) can pass the gate.

## Evidence

Select-String scripts/check.js -Pattern "vocab.js" → only `53:  'flashcards-vocab.js',`; no `data/<lang>` check. Session-audit ledger row 6.

## Minimal fix

Add a check that each `data/<lang>/vocab.js` has ≥1 word, unique `w`, strictly increasing ids, and that its `content/<code>/source.tsv` parses to the same count.

## Acceptance criteria

A deliberately corrupted deck fails `node scripts/check.js`.
