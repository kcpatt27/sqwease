## Summary

The theme toggle is a clickable `<div>` with no role/tabindex/keyboard handler, and its emoji has no accessible name.

## Evidence

`<div class="theme-toggle" onclick="toggleTheme()" title="Toggle dark mode">`; the CSS `:focus-visible` rule can never match a div.

## Proposed fix

Use `<button type="button" aria-label="Toggle dark mode" aria-pressed="...">`, style the button, and update state on toggle.

## Acceptance criteria

Toggle is reachable by Tab, activates with Enter/Space, exposes pressed state, and shows a visible focus ring.
