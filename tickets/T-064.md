## Summary

A catch-all around the tokenized JSON read hides parse errors and emits a build that looks fine.

## Evidence

Broad try/catch falls back silently.

## Proposed fix

Only ignore a genuinely missing optional file; surface parse errors and exit non-zero.

## Acceptance criteria

Malformed JSON fails the build loudly; a missing optional file still builds.
