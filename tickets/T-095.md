## Summary

The multi-language rewrite replaced the per-card hover shadows (green/blue/orange) with a single red; `common.language` is unused and `a11y.themeToggle` duplicates `common.toggleTheme`; boxes `.loading` still uses `#747d8c`.

## Evidence

`.menu a:hover { box-shadow: 0 6px 16px rgba(224,52,63,.2) }` for all cards.

## Proposed fix

Restore per-color hover shadows; delete unused/duplicate i18n keys; use `var(--muted)` for `.loading`.

## Acceptance criteria

Hover colors match card accents; no unused/duplicate keys; loading text meets contrast.
