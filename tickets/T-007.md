## Summary

Token romaji fragments are re-joined with spaces, breaking conjugated verbs and adding a stray period before punctuation.

## Evidence

Tokenized data splits `起き`+`ます` -> `oki`,`masu` and includes a punctuation token with `romaji:"."`, rendering `itsu oki masu ka .` instead of `itsu okimasu ka.`. The README invariant that `romaji` equals space-joined tokens is therefore false.

## Proposed fix

Render the romaji line from the sentence-level romaji and apply token colors by offsets; or join only non-punctuation tokens and suppress the space before CJK punctuation. Correct README-tokenized.md.

## Acceptance criteria

Rendered romaji for tokenized sentences matches the sentence-level romaji exactly (no extra spaces, no stray period).
