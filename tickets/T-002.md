## Summary

SRS/word state is read with a bare `JSON.parse(stored)`; one malformed value throws and aborts the rest of page init.

## Evidence

flashcards.html:462-466 `if (stored) { srsCards = JSON.parse(stored); }` called from initVocab with no try/catch. kanji.html:279-284 already does this correctly and can be copied.

## Proposed fix

Wrap reads in try/catch, fall back to `{}`, and remove/reset the bad key. Reuse one safe-storage helper (see T-060) rather than per-page copies.

## Acceptance criteria

Setting `sqwease-flashcards-srs` (and boxes equivalents) to invalid JSON still loads the page and lets the user study; the corrupt value is replaced on next write.
