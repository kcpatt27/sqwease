## Summary

The spec expects `body[data-target-lang]` / `:lang()` font switching, but the CSS keys off `[lang="ja"|"ko"|"zh"]` while only the flashcards card sets a `lang`. `data-target-lang` is set but never styled, and Japanese content on boxes/kana/kanji is untagged.

## Evidence

Only `flashcards.html:389` sets `lang`; boxes/kana/kanji target-script containers have none.

## Proposed fix

Add `lang` to target-script containers and switch the font rules to `body[data-target-lang="ko"] { … }` (or both).

## Acceptance criteria

Target-language content is tagged and uses the correct font on every page.
