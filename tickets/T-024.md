## Summary

Tautological ternaries, duplicate keys, a no-op normalize block, and a duplicated JSON key add noise and hide the intended normalization.

## Evidence

`box.boxType != null ? box.boxType : box.boxType`, duplicate `boxType:`/`boxName:` keys, `if (!s.boxes && s.boxes) s.boxes = s.boxes;`, and `"slot": "nounsLikes"` twice.

## Proposed fix

Remove all tautologies/duplicates; if an alternate key was intended, normalize it explicitly. Add a duplicate-key lint to the build.

## Acceptance criteria

No no-op/duplicate keys remain; build still produces identical data.
