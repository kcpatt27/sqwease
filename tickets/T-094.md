## Summary

New `aria-label`s ("Display phase", "Previous/Next card", "Activities", "Breadcrumb") are English-only while sibling visible text is translated.

## Evidence

Hardcoded `aria-label` attributes alongside `data-i18n` elements.

## Proposed fix

Add `data-i18n-attr="aria-label:…"` keys for these.

## Acceptance criteria

Accessible names localize with the UI locale.
