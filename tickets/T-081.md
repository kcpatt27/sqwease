## Summary

Several Boxes controls use hardcoded light colors instead of theme tokens, so in
dark mode they render as bright boxes with black text. The practice rating
buttons also still use the pre-fix colors that fail AA contrast (the same ones
already replaced on Flashcards).

## Evidence

Dark-mode scan (theme applied before paint):

- `BUTTON.set-tab` / `BUTTON.mode-tab` background `rgb(255,255,255)` with text
  `rgb(0,0,0)` in dark mode (source: `background: #fff` at lines 117/133).
- `.wordlist-cat { background:#fff; border:1px solid #ddd }` (line 309) and
  `.wordlist-table th, td { border-bottom:1px solid #eee }` (line 313).
- `.loading { color:#747d8c }` (line 304).
- `.rating-btn.again/hard/good/easy` = `#ff6b6b / #ffa502 / #2ed573 / #5352ed`
  with white text (lines 296-303) — the AA-failing palette used before the fix
  applied to Flashcards.

## Proposed fix

- Replace hardcoded colors with tokens (`var(--card-bg)`, `var(--border)`,
  `var(--secondary-text)`) and add any needed dark overrides.
- Copy the AA rating colors from `flashcards.html` (again `#c0392b`, hard
  `#a15c00`, good `#1e8449`, easy `#3d3cc9`).

## Acceptance criteria

- In dark mode no Boxes control renders with a light background; all text meets
  4.5:1.
- The practice rating buttons and word-list remove button meet AA contrast.
