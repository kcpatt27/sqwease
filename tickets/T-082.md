## Summary

The token editor's inputs and secondary buttons keep light backgrounds with black
text in dark mode, so the page is visually broken in the dark theme.

## Evidence

Dark-mode scan (theme applied before paint):

- `INPUT` elements background `rgb(255,255,255)` with text `rgb(0,0,0)`.
- `BUTTON.secondary` background `rgb(240,240,240)`/`#fff` with black text.

## Proposed fix

- Base inputs and secondary buttons on tokens: `background: var(--card-bg)`,
  `color: var(--text)`, `border: 1px solid var(--border)`; add dark overrides
  only where a token is not enough.

## Acceptance criteria

- In dark mode all editor inputs/buttons use dark surfaces with light text and
  meet 4.5:1.
- No regression in the light theme.
