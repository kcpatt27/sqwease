## Summary

Pages hardcode `<html lang="en">` and never mark Japanese content, so screen readers mispronounce it and tooling cannot distinguish languages.

## Evidence

`<html lang="en">` on all six pages; Japanese words/sentences are unmarked.

## Proposed fix

Set html lang from the selected UI locale and add `lang="ja"` (or the active target language) to JA containers and inputs.

## Acceptance criteria

A screen reader switches voice for Japanese text; html lang reflects the chosen UI locale.
