## Summary

All four expanded decks (es/fr/ko/zh, 2,500 words each, branches lang/*-2500) are marked UNREVIEWED. They need a native-speaker pass before they ship as anything but a starter.

## Evidence

Each content/<code>/README.md carries an UNREVIEWED note and per-language limitations (sense selection, inflected forms, MT glosses).

## Proposed fix

Recruit/review per language; fix senses and translations; then flip the status in each README and record the reviewer + date.

## Acceptance criteria

Each deck has a recorded native review; known errors fixed; the README no longer says UNREVIEWED.
