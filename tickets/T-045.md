## Summary

The UI is 100% hardcoded English across markup and JS; no string table exists.

## Evidence

Audit enumerated every literal, from nav labels to rating buttons to dynamic status messages.

## Proposed fix

Add a shared i18n module with locale dictionaries (en/ja/es/fr/ko/zh) and `data-i18n` attributes; route dynamic strings through `t()`. Persist choice; set html lang/dir.

## Acceptance criteria

Switching UI locale updates all chrome strings with no page reload; no untranslated user-facing literal remains in scope.
