## Summary

The "Display" phase selector ("Phase 1/2/3") on the flashcards page is never read
when rendering a card, so changing it has no effect. It is also a Japanese-only
control (it speaks of romaji) yet it is shown for every target language.

## Evidence

- `getRomajiPhase()` (flashcards.html:293) is only used to set the `<select>`
  value at line 487 and to persist on change (line 489); `showCard()` /
  `renderCardFaces()` never consult it. Verified: switching to Phase 2 or 3 and
  studying leaves the pronunciation and definition unchanged.
- The `<option>` labels are `Phase 1 (romaji + definition)` etc. and the control
  is rendered for `es/fr/ko/zh` too, where "romaji" is meaningless.

## Proposed fix

- Apply the phase in `renderCardFaces()` for the Japanese target (hide
  pronunciation at phase ≥2 and the definition at phase 3), matching the intent.
- Hide the whole `.display-phase` block when the active target is not `ja`.
- Add `data-i18n` keys are already present; keep them.

## Acceptance criteria

- Phase 2 hides romaji and Phase 3 shows the word only, on Japanese.
- The control is not shown for non-Japanese targets.
- No console errors; Flashcards still passes the a11y audit.
