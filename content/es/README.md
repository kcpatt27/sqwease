# Spanish deck (`es`)

Frequency-ranked Spanish vocabulary exported from open, licensed datasets.
**2,500 words — UNREVIEWED — needs native-speaker review** before it leaves
"starter" status.

`source.tsv` is the human-editable source; `../data/es/vocab.js` is generated
(`node scripts/build-lang-vocab.js es`). Do not edit the generated file by hand.

## Files

- `source.tsv` — the human-editable source (tab-separated, 2,500 rows).
- `enrich.py` — reproducible source generator: downloads the datasets to a temp
  cache, filters, enriches and emits `source.tsv`. **Not** the runtime builder.
- `../data/es/vocab.js` — generated by `scripts/build-lang-vocab.js`; do not edit.

## Columns

`rank  word  reading  pos  english  example  example_english`

- `rank` — deck order, 1..2500, ascending by corpus frequency.
- `word` — the surface form exactly as it appears in the frequency corpus
  (accents kept; inflected forms and clitic-attached forms included as-is).
- `reading` — IPA pronunciation (no enclosing slashes). Blank if unsourced.
- `pos` — part of speech (`noun`, `verb`, `adj`, `adv`, `det`, `pron`, `prep`,
  `conj`, `num`, `interj`, `contraction`, `part`).
- `english` — English gloss from a dictionary. **No machine translation is
  used anywhere in this deck.**
- `example` / `example_english` — a Tatoeba Spanish/English sentence pair;
  blank if no clean pair was found.

## How it was produced (`enrich.py`)

1. **Filter + dedupe** the 50k frequency list to word-like tokens: at least two
   letters, letters plus internal apostrophes/hyphens only. Single-letter
   tokens (`a`, `y`, `e`, `o`, `u`) and digits/punctuation are dropped. This
   reproduces the committed deck ranking exactly.
2. **Index** the Wiktextract Spanish extract by headword (2 passes): all
   headwords in the top-8,000 enrichment window, then every lemma referenced by
   a `form_of` link or an "X of Y" gloss (so inflected forms can be resolved).
3. **Gloss + POS** from Wiktionary, in priority order:
   1. a clean translation on the word's own entry (e.g. `bonito` → "pretty");
   2. an inline gloss carried inside a reference sense — the Wiktionary
      `extra` field (`me` → "me"), text after `:` (`tía` → "aunt"), text after
      `,` (`cuántos` → "how many") or after `;` (`muy` → "very");
   3. otherwise the reference is followed to its lemma and the lemma's gloss is
      used (`está` → `estar` → "to be"; `hija` → "daughter").
   Glosses are cleaned of parentheticals, usage notes and grammatical jargon.
   The POS written out is the POS of the Wiktionary entry that supplied the
   gloss. Words with no licensed gloss are **skipped, never translated**.
4. **Reading**: the Wiktionary IPA of the selected entry, else any Wiktionary IPA
   for the surface form, else the `ipa-dict` `es_ES` entry, else blank.
5. **Examples**: the shortest (8–70 char) Tatoeba `spa-eng` pair containing the
   headword as a token.
6. Words are taken in frequency order until 2,500 resolvable rows are produced;
   the list therefore reaches corpus rank **2,621** (121 skipped — proper names
   like `john`/`tom`, English words like `the`/`you`, and unglossable
   interjections).

For words that have several Wiktionary entries, the script uses the POS label
already present in the committed `source.tsv` as a *tie-break hint* (this makes
enrichment a fixed point — see below). The POS and gloss written out always come
from the selected Wiktionary entry.

Deterministic: the same inputs reproduce a byte-identical `source.tsv`. Verified
two ways: two consecutive runs with different `PYTHONHASHSEED` produce the same
SHA-256 (`6cb96efe…`), and re-running `enrich.py` on its own emitted
`source.tsv` reproduces the file byte-for-byte. Runtime build is the
dependency-free `scripts/build-lang-vocab.js` (stable `es-0001…` ids).

## Coverage

| Field | Filled | % | Provenance |
|-------|--------|---|------------|
| `word` | 2500 / 2500 | 100.0% | FrequencyWords `es_50k` (CC BY-SA 4.0) |
| `english` | 2500 / 2500 | 100.0% | **dictionary-only (0% machine translation)**: Wiktionary direct 1424 (57.0%), Wiktionary form→lemma 1057 (42.3%), Wiktionary inline 19 (0.8%) |
| `reading` | 2475 / 2500 | 99.0% | Wiktionary IPA 2118 (84.7%); ipa-dict `es_ES` 357 (14.3%); blank 25 (1.0%) |
| `pos` | 2500 / 2500 | 100.0% | Wiktionary (the POS of the gloss-bearing entry) |
| `example` + `example_english` | 2471 / 2500 | 98.8% | Tatoeba `spa-eng` (ManyThings) |

An **independent scorer** re-checks provenance against the raw datasets (does
the gloss text occur among the Wiktionary glosses for the word or a referenced
lemma? does the IPA occur in Wiktionary/ipa-dict? does the POS occur in
Wiktionary?). It reports `english` 99.8% dictionary-sourced (the 5 residual rows
are scorer limitations on accent-folding and second-level lemma chains),
`reading` 98.9% sourced, `pos` 100%, `example` 98.8%.

## Hill-climb score

Score = `0.4·dictionaryGloss% + 0.2·sourcedIPA% + 0.2·pos% + 0.2·example%`
(per-field coverage of the 2,500-row deck).

| Iteration | english (dictionary) | reading (sourced) | pos | example | Score |
|-----------|----------------------|-------------------|-----|---------|-------|
| Branch baseline (`1ceb03e`) | 0.0% (2,500 MT/curated) | 83.6% | 0.0% (MT labels) | 99.1% | 36.5 |
| + Wiktionary gloss/POS resolver (form→lemma, skip unglossable), kaikki-only IPA | 99.8% | 84.7% | 100.0% | 98.8% | 96.6 |
| + inline glosses for function words, + ipa-dict IPA gaps | 99.8% | 99.0% | 100.0% | 98.8% | **99.5** |

The baseline figures are the documented branch provenance (machine/curated
glosses and MT POS labels, 83.6% kaikki IPA, Tatoeba examples). The
machine-translation problem is eliminated: `english` is now 100%
dictionary-sourced. `english`, `reading`, `pos` and `example` all meet their
≥95% targets.

## Known limitations

- The corpus is OpenSubtitles, so the list mixes lemmas with inflected and
  clitic-attached forms; glosses for inflected tokens describe the underlying
  lemma, not the surface grammar (`vamos` → "to go").
- Sense selection on polysemes and homographs is automatic and imperfect
  (`lo` → "that"; `escucha` → "to listen to"). These are Wiktionary senses, not
  translations, and need native review.
- 67 accentless corpus variants duplicate an accented form (`aqui`/`aquí`,
  `asi`/`así`, `estan`/`están`); they are kept because they are separate
  frequency entries, but should be merged on review.
- The list contains vulgar language (e.g. `puta`, `coño`, `cabrón`) because it
  ranks the raw subtitle corpus; review before classroom use.
- 25 rows (1.0%) have no licensed IPA and 29 rows (1.2%) no clean Tatoeba pair
  (many are clitic-attached imperatives such as `déjame`, `ayúdame`).
- Readings are 14.3% from the experimental, rule-generated `ipa-dict es_ES`
  list, not a human-checked dictionary; spot-check stress and seseo/ceceo.

## Review checklist

- [ ] Native-speaker spot check (glosses, IPA, naturalness).
- [ ] Fix sense choices on the top ~200 homographs.
- [ ] Merge accentless variants with their standard forms.
- [ ] Confirm the IPA convention (no slashes) and spot-check the ipa-dict rows.
- [ ] Accept/expand toward 5,000 words if quality holds.

## Reproduce

```bash
# downloads to $TMP/sqwease-es-src on first run, then regenerates source.tsv
python content/es/enrich.py
node scripts/build-lang-vocab.js es
node scripts/check.js
```

Or with an explicit cache/output:

```bash
python content/es/enrich.py <workdir-with-inputs> content/es/source.tsv 2500
```
