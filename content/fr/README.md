# French deck (`fr`)

Frequency-ranked French vocabulary exported from open datasets. **2,500 words,
UNREVIEWED — needs native-speaker review** before it leaves "starter" status.

## Files

- `source.tsv` — the human-editable source (tab-separated, 2,500 rows).
- `enrich.py` — one-shot source generator (regenerates `source.tsv` from the
  datasets below; **not** the runtime builder).
- `../data/fr/vocab.js` — generated by `scripts/build-lang-vocab.js`; do not edit.

## Columns

`rank  word  reading  pos  english  example  example_english`

- `rank` — deck order, 1..2500, ascending by corpus frequency.
- `word` — the surface form as it appears in the frequency corpus (accents kept).
- `reading` — IPA pronunciation (no enclosing slashes). Blank if unsourced.
- `pos` — part of speech (noun, verb, adj, adv, pron, det, art, prep, conj, num,
  interj, phrase, onom).
- `english` — English gloss.
- `example` / `example_english` — a Tatoeba French/English sentence pair; blank
  if no clean pair was found.

## How it was produced (`enrich.py`)

1. **Filter + dedupe** the 50k frequency list to word-like tokens: at least two
   letters, letters plus internal apostrophes/hyphens only. Bare elided prefixes
   (`l'`, `d'`, `j'`, `qu'`, …) are dropped because the corpus tokeniser split
   clitics; their full forms (`le`, `de`, `je`, `que`, …) remain. Single-letter
   tokens (`a`, `à`, `y`) and digits/punctuation are dropped per the deck recipe.
2. **POS + reading** from Lexique 4: the dominant grammatical category for the
   surface form (max `FreqMot`) sets `pos`; `3_Phono_IPA` sets `reading`, with
   the kaikki IPA for the selected sense as fallback.
3. **English** from kaikki / Wiktextract: the first sense of the entry matching
   the Lexique POS. Inflected forms and alt-spellings are resolved to their
   lemma/reference (from kaikki `form_of`, or Lexique's lemma) so a card shows a
   translation, not "third-person singular of …". Gloss cleanup strips
   parentheticals, usage notes and "literally/synonym/contraction of" wrappers.
4. **Examples** from Tatoeba: the shortest `fra-eng` pair (8–70 chars) that
   contains the headword as a token.
5. Words with no English gloss are skipped, so the 2,500 rows span the top
   **2,713** filtered corpus forms (213 skipped: 212 absent from Wiktextract —
   proper nouns, English words, hyphenated clitic phrases like `est-ce` /
   `avez-vous` — and 1 usage-only, `parce`).

The script is deterministic: the same four inputs reproduce a byte-identical
`source.tsv` (no network, no randomness). Runtime build is the dependency-free,
deterministic `scripts/build-lang-vocab.js` (`fr-0001`… stable ids).

## Reproduce

```bash
work=$(mktemp -d)
curl -L -o "$work/fr_50k.txt"        https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/fr/fr_50k.txt
curl -L -o "$work/Lexique400.zip"    http://www.lexique.org/databases/Lexique400/Lexique400.zip
curl -L -o "$work/kaikki-fr.jsonl.gz" https://kaikki.org/dictionary/French/kaikki.org-dictionary-French.jsonl.gz
curl -L -o "$work/fra-eng.zip"       https://www.manythings.org/anki/fra-eng.zip

python content/fr/enrich.py "$work" content/fr/source.tsv 2500
node scripts/build-lang-vocab.js fr
node scripts/check.js
```

## Review checklist

- [ ] Native-speaker spot check (grammar, elision, natural translations).
- [ ] Confirm the `reading` convention (IPA) and spot-check liaisons.
- [ ] Fix sense choices on polysemes: e.g. `accord`="chord" (want "agreement"),
      `mort`="dead person" (want "death").
- [ ] Merge unaccented corpus variants that duplicate a standard form:
      `etre`→`être`, `etait`→`était`, `coeur`→`cœur`, `soeur`→`sœur`,
      `voila`→`voilà`, `plait`→`plaît`, `allo`→`allô`.
- [ ] Review closed-class glosses (`les`="them", `des`="of the").
- [ ] Confirm inflected forms glossed via their lemma (`est`="to be") are
      acceptable, or gloss the exact English inflection.
