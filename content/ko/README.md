# Korean deck (`ko`)

Frequency-ranked Korean vocabulary exported from open, licensed datasets.
**2,500 words — UNREVIEWED — needs native-speaker review** before it leaves
"starter" status.

`source.tsv` is the human-editable source; `../../data/ko/vocab.js` is generated
(`node scripts/build-lang-vocab.js ko`). Do not edit the generated file by hand.

## Files

- `source.tsv` — the human-editable source (tab-separated, 2,500 rows).
- `enrich.py` — reproducible source generator: downloads the datasets to a temp
  cache, filters, enriches and emits `source.tsv`. **Not** the runtime builder.
- `romaja.py` — Revised Romanization (RR) fallback used where Wiktionary has no
  romanization for the exact surface form. Committed so readings are reproducible.
- `../../data/ko/vocab.js` — generated by `scripts/build-lang-vocab.js`; do not edit.

## Columns

`rank  word  reading  pos  english  example  example_english`

- `word` — the surface token exactly as it appears in the frequency corpus
  (whitespace-delimited eojeol, so inflected forms and particle-attached words
  such as `내가`, `있어요`, `집에` are included as-is).
- `reading` — Revised Romanization (RR), lower-case, no syllable separators.
- `pos` — part of speech where sourced; blank when unknown.
- `english` — English gloss from a dictionary (Wiktionary/Wiktextract or
  kengdic). **No machine translation is used.**
- `example` / `example_english` — a Tatoeba (ManyThings export) Korean–English
  sentence pair, or a Wiktionary example sentence with its English translation.

## How it was produced (`enrich.py`)

1. **Filter + dedupe** `ko_50k.txt` to tokens containing at least one Hangul
   syllable; drop control characters and pure-Latin rows; take the top 6,000 as
   the enrichment window.
2. **Index** the Wiktextract Korean extract by headword, and build a reverse
   index of its `forms` tables (inflected/conjugated surface → lemma + POS).
   Load **kengdic** as a fallback gloss source.
3. **Resolve** each surface token, in order:
   1. a curated contraction map for common 것/뭐 contractions (`거야`→것, `그건`→그것 …);
   2. a direct Wiktionary entry for the exact token;
   3. the reverse *forms* index (conjugated verb/adjective forms → lemma);
   4. a kengdic exact match;
   5. case-particle stripping (`집에`→`집`);
   6. verb-ending stripping (`있었는데`→`있다`).
   Glosses named as `form of X` / `contraction of X` / `see X` / `synonym of X`
   are followed to `X` and the lemma's gloss is used. Words that resolve to no
   licensed gloss are **skipped**, never translated. The top 2,500 resolvable
   tokens are taken (the list therefore reaches corpus rank 2,693; 193 skipped).
4. **POS** comes from the Wiktionary entry that produced the gloss.
5. **Reading**: the Wiktionary `romanization` form of the exact token when it
   exists, otherwise the committed RR script `romaja.py`. The script handles
   liaison, nasal / ㄹ assimilation, ㅅ·ㅈ nasalization, ㅎ-aspiration and
   palatalization; it is validated against every Wiktionary romanization in the
   window (agreement **99.4%**, 1455/1464 — the 9 disagreements are
   Wiktionary's over-literal `h` at morpheme boundaries, e.g. `특히` `teukhi` vs
   standard `teuki`).
6. **Examples**: shortest (6–80 char) Tatoeba pair containing the token, else
   the token's lemma; else a Wiktionary example sentence with an English
   translation.
7. A small **curated closed-class map** (12 words: `내`, `우리`, `못`, `안`, `네`,
   `제`, `난`, `다`, `어떻게`, `할`, `제가`, `우린`) picks the learner-relevant
   sense *among Wiktionary/kengdic senses* where entry order is misleading.

Deterministic: the same inputs reproduce a byte-identical `source.tsv` (verified:
two consecutive runs → identical SHA-256). Runtime build is the dependency-free
`scripts/build-lang-vocab.js` (stable ids).

## Hill-climb score

Score = `0.4·dictionaryGloss% + 0.2·sourcedReading% + 0.2·pos% + 0.2·example%`
(per-field coverage of the 2,500-row deck; based on the reviewed-source
provenance, not tuning).

| Iteration | english (dictionary) | reading (sourced) | pos | example | Score |
|-----------|----------------------|-------------------|-----|---------|-------|
| Branch baseline (`4acfb02`) | 25.4% | 38.1% | 26.6% | 0.0% | 23.1 |
| + resolver (Wiktionary + kengdic + morphology), skip unglossable | 100.0% | 32.1% | 94.4% | 91.2% | 83.5 |
| + gloss selection (form-ref resolution, contractions, curated closed class) | 100.0% | 32.1% | 94.5% | 91.2% | 83.6 |
| + committed/validated RR fallback (reading provenance) | 100.0% | 32.1% | 94.5% | 91.2% | 83.6 |

The machine-translation problem is eliminated (baseline had 1,865 MT/curated
glosses; now 0 MT). `english`, `pos` and `example` meet their targets. The
**sourced-reading target (≥95%) is not reachable** with licensed sources:
Wiktionary romanizes lemmas/headwords only, and the frequency list is dominated
by inflected surface eojeol, so only 32.1% of the exact surface forms carry a
Wiktionary romanization. The remaining 67.9% use the committed `romaja.py`,
validated at 99.4% agreement against Wiktionary.

## Known limitations

- The corpus is OpenSubtitles, so the list contains inflected endings,
  particle-attached forms and character names — not a lemma list. Glosses for
  inflected tokens describe the underlying lemma, not the surface grammar.
- Sense selection on polysemes and single-syllable homographs is automatic and
  imperfect (e.g. `해` card shows "the Sun"; `전` "before"; `저` "that"). These
  are Wiktionary/kengdic senses, not translations, and need native review.
- The 12 curated closed-class glosses are a *selection among dictionary senses*,
  recorded here so the choice is auditable.
- 8.8% of rows have no clean licensed example sentence; `example` is blank there.
- Readings are 67.9% algorithmically derived (validated, not native-checked).

## Review checklist

- [ ] Native-speaker spot check (glosses, romanization, naturalness).
- [ ] Fix sense choices on the top ~200 homographs (`해`, `전`, `저`, `네` …).
- [ ] Confirm Revised Romanization consistency (esp. derived rows).
- [ ] Accept/expand toward 5,000 words if quality holds.
- [ ] Confirm `source.tsv` has no duplicate `word` and stable ids.

## Reproduce

```bash
# downloads to $TMP/sqwease-ko-src on first run, then regenerates source.tsv
python content/ko/enrich.py
node scripts/build-lang-vocab.js ko
node scripts/check.js
```

Or with an explicit cache/output:

```bash
python content/ko/enrich.py <workdir-with-inputs> content/ko/source.tsv 2500
```

The full Tatoeba exports (`kor_sentences.tsv.bz2`, `eng_sentences.tsv.bz2`,
`links.tar.bz2`) are used only if already present in the cache; the ManyThings
`kor-eng.zip` alone covers the same 2,500-word window.
